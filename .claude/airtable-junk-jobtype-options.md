Generated 2026-09-08 from the live base.

row whose Job Type was every service comma-joined. Zapier's typecast created a
new dropdown option for each of those strings. They are not real job types.

**How to delete:** in Airtable, open the **Jobs** table → **Job Type** field →
Customize field type → scroll the options list → delete each option below.
Airtable will ask what to do with rows still using it — those are the 161
rows in the worklist (Deliverable 2); it is fine to clear the value, the app
reads Job Type from the row text regardless. Do NOT delete anything not listed here.

**Keep the field open to new values.** If it rejected unknown input the sync would
error and the job row would never be created — a mistyped job type is the lesser evil.
